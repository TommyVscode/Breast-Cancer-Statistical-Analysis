# Statistical Investigation of Breast Cancer Diagnosis and Prediction

This repository contains a Complex Engineering Project (CEP) completed for the course STA281 (Statistical Methods and Probability) in Spring 2026.

## 📌 Project Aim
To statistically differentiate between Malignant (Cancerous) and Benign (Non-cancerous) breast tumors using the Breast Cancer Wisconsin Dataset.

## 🛠️ Tech Stack & Workflow
- **Language:**  Python
- **Libraries:** Pandas, NumPy, Scipy.stats, Matplotlib, Seaborn
- **Framework:** Exploratory Data Analysis (EDA), Hypothesis Testing (T-Test), Probability (Bayes' Theorem), and Linear Regression.

## 📈 Top Project Takeaways
1. **Bayes' Theorem:** Tumor Radius > 15mm increases malignancy risk to 93.06%. If Radius > 18mm, posterior probability reaches nearly 100%.
2. **T-Test Analysis:** Confirmed highly significant differences in physical attributes between Malignant and Benign groups.
3. **Regression Model:** Built an empirical predictor for Tumor Area based on its mean radius.
